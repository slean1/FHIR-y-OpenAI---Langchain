# Proyecto: Exploración de FHIR, Python y LangChain

Este proyecto tiene como objetivo principal explorar la interacción entre FHIR (Fast Healthcare Interoperability Resources), Python y LangChain. La intención es utilizar datos obtenidos desde un servidor FHIR y agregar valor a esta información mediante el uso de conversaciones que se almacenan en memoria. Esto permite enriquecer los datos iniciales con contexto adicional y generar un flujo conversacional que facilite la toma de decisiones o el análisis de la información.

## Objetivos específicos:
1. Conectar y extraer datos desde un servidor FHIR utilizando Python.
2. Implementar LangChain para gestionar conversaciones y mantener un historial en memoria.
3. Agregar valor a los datos de FHIR mediante el análisis y la interacción conversacional.

Este proyecto busca demostrar cómo la integración de tecnologías modernas puede mejorar la utilidad de los datos en el ámbito de la interoperabilidad en salud.
